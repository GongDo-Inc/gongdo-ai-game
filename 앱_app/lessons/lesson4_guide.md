# 4차시 변경 가이드 📣 — 발표 자료 잘 쓰는 법

> **이 문서는 lesson4.md 를 수업할 때 참고하는 가이드예요.**
> 학생이 자기 게임의 매력을 발견하고 친구들에게 전달할 수 있도록 도와줘요.

---

## ✍️ 발표 입력 칸별 — 좋은 답변 / 나쁜 답변

| 입력 칸 | ❌ 나쁜 예시 | ✅ 좋은 예시 |
|---|---|---|
| **게임 제목** | "내 게임" | "ㅋㅋ의 별 모양 주사위 부루마블" |
| **한 줄 소개** | "재밌어요" | "별 주사위로 세계 도시를 여행하며 부자가 되는 게임!" |
| **재밌었던 순간** | "다요" | "토리 능력으로 5바퀴만에 100만 골드 모았을 때" |
| **어려웠던 부분** | "어려웠어요" | "캐릭터 능력 4개 균형 맞추기. AI에게 '약하게 만들어줘' 라고 물어서 해결" |
| **좋았던 명령** | "예쁘게 해줘" | "보드판을 어두운 우주 배경으로 바꿔줘. 별이 반짝거리면 좋겠어" |
| **보여주고 싶은 장면** | "끝날 때" | "레옹이 황금카드 칸에서 +6000골드 받는 순간" |

---

## 👀 친구 발표 들으며 비교할 포인트

친구가 발표할 때 이런 걸 들어봐요:

1. **친구의 캐릭터 능력은 뭘까?** 내 거랑 어떻게 달라?
2. **친구의 도시 가격은 어떻게 정했지?** 나보다 비싼가? 싼가?
3. **친구가 AI에게 한 명령 중 내가 못 떠올린 게 있어?**
4. **친구의 게임은 누가 잘 이기게 만들어졌어?**
5. **나도 다음에 따라하고 싶은 부분이 있어?**

→ 듣고 나서 친구에게 **"네 게임의 ㅇㅇ이 진짜 좋았어"** 한 마디 칭찬해주기!

---

## 💬 AI튜터로 발표문 다듬는 법

### 발표문 만들기
- "이 게임을 30초 안에 소개하는 발표문 써줘"
- "내가 적은 한 줄 소개를 더 재밌게 다듬어줘"

### 긴장 풀기
- "발표할 때 긴장돼. 어떻게 하면 좋아?"
- "처음에 인사를 어떻게 하면 좋을까?"

### 답변 다듬기
- "이 문장이 좀 어색해. 자연스럽게 바꿔줘: [내 문장]"
- "초등학생 친구들에게 더 잘 와닿게 바꿔줘"

---

## 🤔 1·2·3차시 회고 질문 (메타인지)

발표 자료를 다 채운 후, 친구들에게 발표하기 전에 스스로 물어봐요:

| 차시 | 회고 질문 |
|---|---|
| 1차시 | "주사위·보드판을 만들 때 가장 헷갈렸던 게 뭐였어?" |
| 2차시 | "AI튜터에게 도시 정보 물었을 때 어떤 점이 신기했어?" |
| 3차시 | "캐릭터 능력 균형을 맞추려고 어떤 고민을 했어?" |
| 전체 | "AI에게 부탁할 때 한 번에 잘 안 되면 어떻게 했어?" |

## 🎓 선생님 메모

### 4차시 학습 목표 (배경 설명)
- **메타인지** — 자기 학습 과정을 되돌아보기
- **산출물 커뮤니케이션** — 결과물을 다른 사람에게 설명
- **AI 협업 정리** — 어떤 명령이 효과적이었는지 패턴 발견

### 학생 진도 체크 포인트
- [ ] 발표 입력 칸 6개를 모두 채웠는가?
- [ ] "재미 포인트"를 구체적으로(예시까지) 적었는가?
- [ ] 패들렛에 자기 게임 공유 주소를 올렸는가?
- [ ] 친구 발표 1명 이상에게 칭찬 한 마디 했는가?

### 발표 운영 팁
- **발표 시간**: 1인당 1분 30초 제한 (전원 발표 가능하도록)
- **순서**: 자원 발표 후, 자원자가 다음 친구 지목 (참여 분위기)
- **선생님 코멘트**: "ㅇㅇ 부분이 인상적이었어요" 식 구체 칭찬

### 자주 발생하는 이슈
- **재미 포인트가 안 떠오를 때**: "내 게임에서 다른 친구 게임이랑 다른 점은 뭐야?"
- **발표가 너무 짧을 때**: "재미 포인트를 한 가지만 더 구체적으로 말해보자"
- **패들렛 공유 안 될 때**: 게임 공유 주소가 만들어졌는지 먼저 확인

### 수업 마무리
4차시 끝에 학생 전체에게 한 번 더 강조:
> **"여러분이 오늘 만든 게임은 진짜 게임 개발자가 만든 거예요. 이건 진짜 작품입니다!"**

→ 학생의 자기효능감을 정점으로 끌어올린 후 마무리.
