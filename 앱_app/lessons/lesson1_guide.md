# 1차시 변경 가이드 🎲 — 어디를 바꾸면 어떻게 변할까?

> **이 문서는 lesson1.md 를 수업할 때 참고하는 가이드예요.**
> 학생이 막히면 함께 보면서 변형 아이디어를 떠올려요.

---

## 🎯 핵심 변경 포인트 5가지

| 영역 | 변경 전 (기본값) | 변경 후 (예시) | 게임에 나타나는 변화 |
|---|---|---|---|
| **칸 수** | 12칸 | 10칸 / 14칸 | 칸이 커지거나 많아져서 느낌이 달라져요 |
| **주사위 모양** | 일반 주사위 | 별 모양 / 하트 모양 | 주사위 굴릴 때 다른 모양이 나타나요 |
| **배경 분위기** | 하늘색 교실 느낌 | 노을 / 우주 / 바다 | 뒤 배경이 바뀌어요 |
| **보드판 색** | 크림색 | 민트 / 분홍 / 노랑 | 칸판 색이 달라져요 |
| **핀 색** | 빨강 / 파랑 | 초록 / 주황 | 내 말 색이 달라져요 |

---

## 🌈 시도해볼 변형 7가지

1. **"주사위를 별빛 주사위로 바꿔줘"** → 버튼과 주사위 모양이 달라져요
2. **"뒤 배경을 노을 하늘로 바꿔줘"** → 첫 화면부터 분위기가 바뀌어요
3. **"보드판을 민트색으로 바꿔줘"** → 칸판이 산뜻해져요
4. **"출발 칸 이름을 우리반 출발로 바꿔줘"** → 시작 칸 이름이 달라져요
5. **"7칸 이름을 무지개 다리로 바꿔줘"** → 특정 칸 제목을 직접 꾸밀 수 있어요
6. **"핀 색을 보라색과 노란색으로 바꿔줘"** → 내 말이 더 잘 보여요
7. **"12칸 대신 10칸으로 줄여줘"** → 더 짧고 쉬운 게임이 돼요

---

## ⚠️ 절대 건드리면 안 되는 부분

다음 형식은 **그대로 두어요**. 크게 깨지면 게임이 이상하게 나올 수 있어요.

```md
## 보드판
- 12칸 보드판

### 칸 목록
- 0칸: 출발 / 한 바퀴 돌면 2000골드
```

---

## 💬 AI튜터에게 묻는 좋은 예시

- ❌ "이거 어떻게 해요?" (너무 막연해요)
- ✅ "주사위를 별 모양으로 바꾸고 싶은데 어떻게 말해야 해?"
- ✅ "보드판을 무지개색으로 바꾸려면 어떻게 부탁해?"
- ✅ "내 게임이 너무 빨리 끝나요. 더 길게 하려면?"

## 🎓 선생님 메모

### 1차시 학습 목표 (배경 설명)
- AI에게 자연어로 요청하는 첫 경험
- "[무엇을] [어떻게] [왜]" 3원칙 체득
- 보드게임 메커니즘 이해 (주사위·칸·골드·승리 조건)

### 학생 진도 체크 포인트
- [ ] 학생이 [▶ 시작] 버튼을 눌러 게임이 한 번 실행되는가?
- [ ] 주사위 굴리기 버튼이 동작하는가?
- [ ] 학생이 한 가지라도 본문을 변형해서 다시 [▶ 시작] 했는가?
- [ ] AI튜터에게 한 번이라도 질문했는가?

### 자주 발생하는 이슈
- **칸 수가 안 바뀔 때**: `- 12칸 보드판`처럼 숫자를 분명하게 적었는지 확인
- **주사위가 안 보일 때**: `### 주사위` 영역에 이름이 남아있는지 확인
- **너무 어려워할 때**: 위 변형 7가지 중 1번이나 2번부터 시작 권장
