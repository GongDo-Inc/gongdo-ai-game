# 3차시 변경 가이드 🎨 — 넷마블 캐릭터 친구들과 함께하기

> **이 문서는 lesson3.md 를 수업할 때 참고하는 가이드예요.**
> 핀으로 시작해서 넷마블 캐릭터로 전환하고, 시작 금액까지 직접 바꿔봐요.

---

## 🎯 핵심 변경 포인트 5가지

| 영역 | 변경 전 (기본값) | 변경 후 (예시) | 게임에 나타나는 변화 |
|---|---|---|---|
| **주인공** | 빨간 핀 | 데니스 | 핀이 진짜 캐릭터 이미지로 변해요 |
| **AI친구** | 파란 핀 | 슬기 | AI 상대가 캐릭터로 등장해요 |
| **시작 금액** | 30,000 | 50,000 / 10,000 등 | 게임 난이도와 전략이 달라져요 |
| **도시 가격** | 5,000~9,600골드 | 도시 가격 직접 교체 | 통행세·매입 전략이 바뀌어요 |
| **배경** | 지구본 맵 (고정) | 그대로 유지 | 보드판 위에서 세계여행 분위기 유지 |

---

## 💡 수업 흐름 — 단계별 활동

### 1단계: 핀으로 시작
바이브코딩 문서를 열면 기본값은 **빨간 핀(주인공)** + **파란 핀(AI친구)** 이에요.
[시작] 버튼을 눌러 핀이 보드 위를 움직이는 걸 확인해요.

### 2단계: 캐릭터로 바꾸기 🎭
문서에서 `### 플레이어 핀` 섹션을 찾아 값을 바꿔요:
```
### 플레이어 핀
- **주인공** : 데니스    ← "빨간 핀" → "데니스"
- **AI친구** : 슬기     ← "파란 핀" → "슬기"
```
[시작] 버튼을 다시 누르면 핀이 데니스·슬기 캐릭터 이미지로 바뀌어요!

### 3단계: 시작 금액 바꾸기 💰
`### 규칙` 섹션 맨 위 두 줄에서 숫자를 바꿔요:
```
### 규칙
- 주인공 : 50,000골드     ← 더 많은 돈으로 시작
- AI친구 : 30,000골드     ← AI는 적게 (나에게 유리)
- 출발 칸 통과: +2000골드
- ...
```
시작 금액에 따라 게임 양상이 완전히 달라져요!
또는 AI튜터에게 `"시작 금액을 50000골드로 바꿔줘"` 처럼 부탁할 수도 있어요.

## 💡 시도해볼 꾸미기 아이디어 8가지

1. "주인공을 데니스로, AI친구를 슬기로 바꿔봐요"
2. "주인공 시작 금액을 100,000으로 늘려봐요"
3. "AI친구 시작 금액을 5,000으로 줄여봐요 (도전모드!)"
4. "주사위를 별 모양 주사위로 바꿔봐요"
5. "서울 가격을 1,000골드로 확 낮춰봐요"
6. "런던 가격을 30,000골드로 비싸게 만들어봐요"
7. "37칸 베를린을 우리나라 제주도로 바꿔봐요"
8. "음악을 신나는 우주 전투 음악으로 바꿔봐요"

## ⚠️ 절대 건드리면 안 되는 부분

다음 **이미지 URL** 들은 그대로 두어요. 지우면 캐릭터 그림이 안 나와요!

```
/assets/characters/archive/dennis.png
/assets/characters/archive/seulgi.png
/assets/backgrounds/worldmap.jpg
```

→ 캐릭터 이름(데니스·슬기), 도시 이름, 시작 금액 숫자만 바꿔요.

## 🎓 선생님 메모

### 3차시 학습 목표 (배경 설명)
- 외부 자산(IP 캐릭터·지구본맵)이 코드와 어떻게 결합되는지 체험
- 이름 한 단어 바꾸기로 캐릭터 분기가 일어나는 걸 체감 (변수 개념)
- 시작 금액 = 변수 = 게임 난이도 조절 도구라는 걸 학습
- 너무 많은 요소를 한 번에 바꾸지 않고 핵심만 다듬는 경험

### 학생 진도 체크 포인트
- [ ] 핀 모드에서 캐릭터 모드로 전환을 직접 했는가?
- [ ] 시작 금액을 1번 이상 바꿔서 게임 양상 차이를 체감했는가?
- [ ] 자기가 만든 게임을 5분 이상 플레이했는가?
- [ ] AI튜터에게 도시나 시작 금액 아이디어를 1번 이상 물었는가?

### 자주 발생하는 이슈
- **핀이 캐릭터로 안 바뀔 때**: `### 플레이어 핀` 섹션 값에 "데니스" 혹은 "슬기" 정확히 적었는지 확인 (오타·공백 X)
- **이미지가 안 보일 때**: dennis.png / seulgi.png URL이 정확한지 확인
- **시작 금액 반영 안 될 때**: `### 규칙` 안에 `- 주인공 : 50000골드` 형식인지, 콜론과 숫자 사이 공백 확인
- **뭘 바꿔야 할지 모르겠을 때**: 위 8가지 아이디어 중 하나를 골라 그대로 적용
- **지구본 맵이 깨질 때**: 배경 이미지 URL 중 worldmap 부분 확인

### 황금카드 칸 안내
2차시까지 보이던 화투패 🎴 아이콘은 3차시부터 **황금키 🔑** 로 통일되었어요.
이름은 그대로 "황금카드" 지만 이미지가 열쇠로 바뀌어 더 안전하고 명확해졌어요.
