# 3차시 🎨 캐릭터와 배경 꾸미기

**오늘의 목표**: 캐릭터를 고르고 배경을 바꿔서 내 보드게임 분위기를 완성해봐요!

---

## 💡 오늘의 비밀

같은 게임도 **캐릭터와 배경이 바뀌면** 완전 다른 느낌이에요.
- 보드판 배경을 바꾸면 게임 분위기가 달라져요.
- 핀 대신 캐릭터가 나오면 더 생생해져요.
- 데니스와 슬기를 넣으면 게임이 더 생생해져요.

---

## 🎮 내가 만들 게임

### 장르
모두의 블루마블 (캐릭터와 배경 꾸미기)

### 주인공
- 주인공: 데니스 (이미지: https://gongdo-ai-game.vercel.app/에셋_assets/캐릭터_characters/archive/dennis.png)

### 상대
- 상대: 슬기 (이미지: https://gongdo-ai-game.vercel.app/에셋_assets/캐릭터_characters/archive/seulgi.png)

### 배경
- 배경: 지구본 맵 (이미지: https://gongdo-ai-game.vercel.app/에셋_assets/배경_backgrounds/worldmap_1920.jpg)
- 배경색: 기본색
- 보드판이 지구본 위에 올라가 있어요

## 보드판
- 12칸 보드판
- 보드 색상: 크림색

### 조작 방법
- [🎲 주사위 굴리기] 버튼 한 번 누르기
- 캐릭터가 자동으로 칸 이동

### 도시 목록
- 1칸 : 대한민국 서울: 경복궁 / 5000골드
- 2칸 : 일본 도쿄: 도쿄타워 / 5200골드
- 3칸 : 중국 베이징: 만리장성 / 5400골드
- 4칸 : 프랑스 파리: 에펠탑 / 5600골드
- 5칸 : 이탈리아 로마: 콜로세움 / 5800골드
- 6칸 : 미국 뉴욕: 자유의여신상 / 6000골드
- 7칸 : 영국 런던: 빅벤 / 6200골드
- 8칸 : 이집트 카이로: 피라미드 / 6400골드
- 9칸 : 호주 시드니: 오페라하우스 / 6600골드
- 10칸 : 브라질 리우: 예수상 / 6800골드
- 11칸 : 인도 뉴델리: 타지마할 / 7000골드

### 규칙
- 출발 칸 통과: +2000골드
- 도시 매입 / 통행세 / 황금카드 / 세금 / 여행 / 무인도 / 보너스 칸 (2차시와 동일)
- **5바퀴 후 가장 부자** = 승리! 🏆
