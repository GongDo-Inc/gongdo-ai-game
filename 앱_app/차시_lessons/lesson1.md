# 1차시 🎲 모두의 블루마블

**오늘의 목표**: 친구들과 주사위를 굴려서 **세계 일주**를 떠나봐요!

---

## 🎮 어떻게 노는 거예요?

오른쪽 게임판은 **세계 지도** 위에 40개의 칸이 동그랗게 놓여 있어요.
**나** (데니스 🎭 또는 슬기 🎀) 와 **🤖 AI 친구**(로봇) 가 번갈아가며 주사위를 굴려서 칸을 이동해요.
**한 바퀴를 돌면 월급 +2,000골드** 를 받아요!

---

## ⚙️ 내 게임 만들기 (마음대로 바꿔봐요!)

> 👇 아래 항목들을 바꾸고 [▶ 시작]을 누르면 내 게임이 만들어져요!

- **내 캐릭터**: 데니스
- **내 이름**: 데니스
- **승리 골드**: 50,000골드
- **주사위 개수**: 2개
- **음악(BGM)**: 모험

### 💡 바꿀 수 있는 값들

| 항목 | 가능한 값 |
|:---|:---|
| **내 캐릭터** | `데니스` 또는 `슬기` |
| **내 이름** | 마음대로 (예: `수민`, `최강레옹`) |
| **승리 골드** | `30,000골드` (짧은 게임) / `50,000골드` (보통) / `100,000골드` (긴 게임) |
| **주사위 개수** | `1개` (천천히) / `2개` (보통) / `3개` (빨리빨리!) |
| **음악(BGM)** | `모험` / `잔잔` / `신남` / `끄기` |

---

## 🕹️ 조작 방법

- 👉 [**주사위 굴리기**] 버튼을 누르면 주사위가 굴러가요
- 주사위 합계만큼 칸을 이동해요
- 칸을 **클릭**하면 어떤 칸인지 알려줘요
- AI 친구는 자기 차례에 자동으로 굴려요 — 기다려주세요

---

## 📍 칸의 종류

| 칸 | 효과 |
|:---|:---|
| 🚩 **출발** | 한 바퀴 돌면 월급 +2,000골드 |
| 🏯 **도시** | 여행 인증! 칸 정보를 볼 수 있어요 |
| 🎴 **황금카드** | -2,000 ~ +3,000골드 |
| 💰 **세금** | 세금 -1,000골드 |
| ✈️ **여행** | 다음 여행 칸으로 점프! |
| 🏝️ **무인도** | 3턴 동안 주사위를 못 굴려요 |
| 🚀 **우주여행** | 아무 칸으로 텔레포트! |
| 🎁 **사회복지** | 보너스 +2,000골드 |

---

## 💬 막혔을 때

오른쪽 아래 **AI튜터** 버튼을 눌러 공도쌤에게 물어봐요!
"어떻게 바꿔야 할지 모르겠어요" 라고만 해도 친절하게 알려줄 거예요.
