# 🎲 모두의 블루마블 — 바이브코딩 4차시 커리큘럼

> 초등학생이 AI에게 자연어로 부탁해서 「모두의 블루마블」 보드게임을 만들어보는 4차시 바이브코딩 + AI 리터러시 학습 패키지.

---

## 📚 4차시 커리큘럼

| 차시 | 주제 | 학생 활동 |
|---|---|---|
| **1차시** 🎲 | 모두의 블루마블 만들기 | 주사위 + 보드판(28칸) 구조 잡기. 칸별 효과 7종 정의 |
| **2차시** 🌍 | 도시별 규칙 만들기 | AI튜터에게 국가별 수도·문화유적 묻고 칸 채우기 |
| **3차시** 🎨 | 캐릭터 + 지구본 맵 | 데니스·슬기 캐릭터와 지구본 맵으로 분위기 완성 |
| **4차시** 📣 | 발표 자료 + 공유 | 내가 만든 게임을 친구들에게 소개 + 패들렛 공유 |

---

## 📂 파일 구성 (8개)

### 학생용 — `lesson{N}.md`
학생이 게임 앱의 textarea 영역에 그대로 노출되는 본문. AI가 이 본문을 받아 보드게임 HTML을 생성합니다.

- `lesson1.md` — 모두의 블루마블 만들기
- `lesson2.md` — 도시별 규칙 만들기
- `lesson3.md` — 캐릭터 IP + 지구본 맵
- `lesson4.md` — 발표 자료 + 공유

### 선생님·운영용 — `lesson{N}_guide.md`
변경 포인트 / 시도해볼 변형 / 절대 건드리면 안 되는 부분 / AI튜터 활용법 / 선생님 메모를 담은 보조 문서.

- `lesson1_guide.md`
- `lesson2_guide.md`
- `lesson3_guide.md`
- `lesson4_guide.md`

---

## 🛠 사용 방법

### 학생
1. 공도 AI-Game 앱에 진입 → 차시 선택
2. textarea에 lesson 본문이 자동 노출 → 마음대로 변형
3. **[▶ 시작]** 버튼 → AI가 게임 HTML 생성
4. 막히면 **AI튜터** 버튼

### 선생님
1. 수업 전 — `lesson{N}_guide.md` 의 "선생님 메모" 정독
2. 수업 중 — 학생이 막히면 가이드의 "변경 포인트" / "변형 예시" 함께 읽기
3. 수업 후 — 가이드의 "학생 진도 체크 포인트" 로 이수도 확인

## ⚠️ 작성 규칙 (편집 시 반드시 지키기)

1. `- 주인공:` 라인은 모든 차시에 존재 — 캐릭터 IP 자동 입력 정규식 매치 보존
2. lesson 본문 = 게임 명세(프롬프트 자료) — 페다고지 안내문 X
3. 이미지 URL = 절대 URL (`https://gongdo-ai-game.vercel.app/에셋_assets/...`) 만 사용
4. 모든 파일에 deploy_header(HTML 주석) 유지 — 앱이 자동 stripping
5. 본문 수정 시 deploy_header 의 `@version` / `@updated` / 변경 이력 누적
