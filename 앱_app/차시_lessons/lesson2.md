# 2차시 🌍 도시별 규칙 만들기

**오늘의 목표**: 1차시에서 만든 12칸 보드판 위에 도시 이름, 설명, 가격 규칙을 넣어봐요!

---

## 💡 도시 칸의 3가지 비밀

도시 한 칸에는 항상 3가지가 들어가요:

1. **몇 번 칸인지** — 예: "3칸"
2. **나라·수도·상징 건축물** — 예: "한국 서울: 경복궁"
3. **통행세** — 예: "5000골드"

→ "**3칸 : 한국 서울: 경복궁 / 5000골드**" 처럼 한 줄로 적어요.

---

### 주사위

### 배경

- 보드 색상: 크림색

### 조작 방법

- 플레이어 핀이 자동으로 칸 이동

- 0칸: 출발 / 한 바퀴 돌면 2000골드

- 5칸: 도시 칸 / 이미 준비된 도시

- 7칸: 도시 칸 / 내가 채울 칸
- 8칸: 도시 칸 / 내가 채울 칸
- 9칸: 도시 칸 / 내가 채울 칸
- 10칸: 도시 칸 / 내가 채울 칸
- 11칸: 도시 칸 / 내가 채울 칸

### 도시 목록
> ⬇️ 6개는 먼저 넣어두었어요. 나머지 5개 도시는 AI튜터에게 물어보며 채워봐요!

- 1칸 : 대한민국 서울: 경복궁 / 5000골드
- 2칸 : 일본 도쿄: 도쿄타워 / 5200골드
- 3칸 : 중국 베이징: 만리장성 / 5400골드
- 4칸 : 프랑스 파리: 에펠탑 / 5600골드
- 5칸 : 이탈리아 로마: 콜로세움 / 5800골드
- 6칸 : 미국 뉴욕: 자유의여신상 / 6000골드
- 7칸 : __________ / ____골드
- 8칸 : __________ / ____골드
- 9칸 : __________ / ____골드
- 10칸 : __________ / ____골드
- 11칸 : __________ / ____골드

### 도시 설명 메모
- 대한민국 서울: 우리나라의 수도예요. 옛날 임금님이 살던 경복궁이 있어요.
- 일본 도쿄: 일본의 수도예요. 빨갛고 높은 도쿄타워가 멋져요.
- 중국 베이징: 중국의 수도예요. 길게 이어진 만리장성이 유명해요.
- 프랑스 파리: 프랑스의 수도예요. 철로 만든 큰 탑, 에펠탑이 상징이에요.
- 이탈리아 로마: 이탈리아의 수도예요. 옛날 사람들이 경기를 보던 콜로세움이 있어요.
- 미국 뉴욕: 미국에서 제일 큰 도시예요. 자유의여신상이 항구에 서 있어요.
- 내가 채운 칸도 위처럼 두 줄 느낌으로 쉽게 설명해요.

### 규칙
- 출발 칸 통과: +2000골드
- 도시 도착: 위 가격으로 매입
- 다른 사람 도시 도착: 도시 목록의 `/ 뒤 숫자` 만큼 통행세 내기
- 황금카드: -2000 ~ +3000골드
- 세금: -1000골드
- 여행/무인도/보너스 칸도 계속 유지
- **5바퀴 후 가장 부자** = 승리! 🏆
